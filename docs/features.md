# 핵심 기능 명세

## 1. 메인 대시보드

오늘 수집된 정보를 카드 형태로 출력.

**카드 구성 요소:**
- 앱 이름
- 한줄 설명
- 카테고리
- 출처
- 링크
- 저장 버튼

**카테고리 분류:**

| 카테고리 | 예시 |
|----------|------|
| AI 앱 | ChatGPT 류, 이미지 생성 앱 |
| 생산성 앱 | 노트, 캘린더, 태스크 |
| 커뮤니티 앱 | 익명 SNS, 관심사 기반 |
| 루틴 앱 | 습관 트래커, 일기 |
| 감정형 앱 | 감정 기록, 웰니스 |

## 3. 북마크 기능

마음에 드는 앱을 저장.

**저장 항목:**
```
앱 이름    : (텍스트)
링크       : (URL)
메모       : (자유 텍스트)
태그       : #태그1 #태그2
저장일     : (자동)
```

**태그 예시:**

| 태그 | 용도 |
|------|------|
| `#온보딩` | 첫 진입 UX가 인상적인 앱 |
| `#AI채팅` | AI 대화 인터페이스 |
| `#리텐션` | 재방문 유도 구조가 좋은 앱 |
| `#커뮤니티` | 커뮤니티 설계가 탁월한 앱 |
| `#친구초대` | 바이럴 구조 참고 |

## 4. 메모 기능

앱 탐색 중 바로 기록하는 빠른 노트.

**메모 예시:**
```
- 친구 초대 구조 자연스러움
- 첫 진입 UX 빠름 (3초 안에 핵심 기능 도달)
- 감정 리텐션 강함 (streak 구조)
- 온보딩에서 선택지 최소화
```
