# 아이디어 컬렉션

## 개념

아이디어가 떠오를 때 즉시 저장하고,  
나중에 한 장씩 꺼내보며 다듬는 **아이디어 서랍**.

> 입력은 빠르게, 탐색은 천천히. 디벨롭은 린 캔버스 기반으로.

---

## 두 가지 모드

### 1. 빠른 입력 모드 (Quick Add)

아이디어가 떠오른 순간 바로 적는 창.  
형식 없이, 제목 하나만 있어도 저장 가능.

```
┌─────────────────────────────────┐
│  💡 아이디어 빠르게 적기         │
│                                 │
│  제목: [___________________]    │
│  메모: [___________________]    │
│                                 │
│            [ 저장 ]             │
└─────────────────────────────────┘
```

- 제목만 입력해도 저장
- 저장 즉시 입력창 초기화 (계속 입력 가능)
- 상태 기본값: `💡 새 아이디어`
- 린 캔버스 항목은 비워진 채로 저장 → 나중에 채움

---

### 2. 카드 탐색 모드 (Card Browse)

저장된 아이디어를 한 장씩 꺼내보는 뷰.

```
          [ 3 / 17 ]

┌──────────────────────────────┐
│                              │
│   💡 루틴 앱에 감정 기록     │
│      추가하면 어떨까?        │
│                              │
│  카테고리: 앱 아이디어       │
│  태그: #루틴 #감정 #리텐션   │
│  작성일: 2026-05-14          │
│                              │
│  메모:                       │
│  스트릭 + 감정 상태 조합.    │
│  매일 기분을 기록하면        │
│  패턴이 보이지 않을까?       │
│                              │
│  린 캔버스 진행도: ▓▓▓░░░░░░  3/9  │
│                              │
│  [ 🔨 디벨롭 체크리스트 열기 ]│
└──────────────────────────────┘

  [ ← 이전 ]  [ 다음 → ]

  [ 💡 새 아이디어 ]  [ 🔨 발전 중 ]
  [ ✅ 완성 ]        [ 🗑️ 보류 ]
```

- 이전 / 다음 버튼으로 탐색
- 린 캔버스 진행도 프로그레스바 표시 (몇 개 항목 채웠는지)
- 하단 버튼으로 상태 변경
- 상태별 필터 가능

## 디벨롭 체크리스트 — 린 캔버스

아이디어를 "발전 중" 상태로 올릴 때 채우는 9개 항목.  
모두 채울 필요 없음. 생각이 정리될 때마다 하나씩 채워가는 방식.

```
[ 아이디어명: 루틴 앱에 감정 기록 추가 ]
진행도: ▓▓▓░░░░░░  3 / 9

──────────────────────────────────────────
 1. 고객 세그먼트        ✅ 완료
──────────────────────────────────────────
   이 서비스를 쓸 사람은 누구인가?
   [자기 감정 패턴을 모르는 20~30대.      ]
   [번아웃 직전인데 이유를 모르는 직장인.  ]

──────────────────────────────────────────
 2. 가치 제안            ✅ 완료
──────────────────────────────────────────
   고객에게 어떤 가치를 주는가?
   [루틴 + 감정 기록을 조합해서           ]
   [내 감정 패턴을 시각화해준다.          ]

──────────────────────────────────────────
 3. 채널                 ✅ 완료
──────────────────────────────────────────
   어떻게 고객에게 전달할 것인가?
   [앱스토어 + 인스타그램 감성 마케팅     ]

──────────────────────────────────────────
 4. 고객 관계            ░ 미작성
──────────────────────────────────────────
   고객과 어떤 관계를 유지할 것인가?
   [                                     ]

──────────────────────────────────────────
 5. 수익원               ░ 미작성
──────────────────────────────────────────
   어떻게 돈을 벌 것인가?
   [                                     ]

──────────────────────────────────────────
 6. 핵심 자원            ░ 미작성
──────────────────────────────────────────
   서비스 운영에 반드시 필요한 자원은?
   [                                     ]

──────────────────────────────────────────
 7. 핵심 활동            ░ 미작성
──────────────────────────────────────────
   가장 중요하게 해야 할 활동은?
   [                                     ]

──────────────────────────────────────────
 8. 핵심 파트너          ░ 미작성
──────────────────────────────────────────
   누구와 협력해야 하는가?
   [                                     ]

──────────────────────────────────────────
 9. 비용 구조            ░ 미작성
──────────────────────────────────────────
   주요 비용 항목은 무엇인가?
   [                                     ]

──────────────────────────────────────────
                          [ 저장 ]
```

## 아이디어 상태 흐름

```
💡 새 아이디어  (제목만 있어도 OK)
    ↓
🔨 발전 중      (린 캔버스 항목 채우는 중)
    ↓
✅ 완성         (9개 항목 정리 완료 or 기획서 작성)
    or
🗑️ 보류         (지금은 아닌 것 같음, 삭제 안 함)
```

## DB 스키마

```sql
CREATE TABLE ideas (
    id               INTEGER PRIMARY KEY,
    title            TEXT NOT NULL,
    description      TEXT,
    category         TEXT,
    tags             TEXT,               -- 쉼표 구분 문자열
    status           TEXT DEFAULT 'new', -- new / developing / done / hold
    source_date      DATE,               -- 어느 날 메모에서 나온 아이디어인지

    -- 린 캔버스 9개 항목
    lc_customer_segments   TEXT,  -- 1. 고객 세그먼트
    lc_value_proposition   TEXT,  -- 2. 가치 제안
    lc_channels            TEXT,  -- 3. 채널
    lc_customer_relations  TEXT,  -- 4. 고객 관계
    lc_revenue_streams     TEXT,  -- 5. 수익원
    lc_key_resources       TEXT,  -- 6. 핵심 자원
    lc_key_activities      TEXT,  -- 7. 핵심 활동
    lc_key_partners        TEXT,  -- 8. 핵심 파트너
    lc_cost_structure      TEXT,  -- 9. 비용 구조

    created_at  DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at  DATETIME
);
```

### 린 캔버스 진행도 계산

```python
LEAN_CANVAS_FIELDS = [
    "lc_customer_segments",
    "lc_value_proposition",
    "lc_channels",
    "lc_customer_relations",
    "lc_revenue_streams",
    "lc_key_resources",
    "lc_key_activities",
    "lc_key_partners",
    "lc_cost_structure",
]

def lean_canvas_progress(idea: dict) -> tuple[int, int]:
    filled = sum(1 for f in LEAN_CANVAS_FIELDS if idea.get(f))
    return filled, 9  # (채워진 수, 전체)
```

### status 값 정의

| 값 | 표시 | 의미 |
|----|------|------|
| `new` | 💡 새 아이디어 | 방금 적은 것 |
| `developing` | 🔨 발전 중 | 린 캔버스 작성 중 |
| `done` | ✅ 완성 | 린 캔버스 완성 or 기획 완료 |
| `hold` | 🗑️ 보류 | 지금은 보류 |

## 연결 기능

| 출발점 | 도착점 |
|--------|--------|
| 캘린더 메모 → "아이디어로 승격" 버튼 | 아이디어 컬렉션에 자동 저장 |
| 대시보드 북마크 → "아이디어 연결" | 아이디어에 관련 앱 링크 첨부 |
| 아이디어 → source_date 클릭 | 해당 날 캘린더 메모로 이동 |
