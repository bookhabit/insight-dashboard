# 프로젝트 개요

## 목적

매일 20~30분 동안 아래 항목을 빠르게 훑으며 **앱 기획 감각과 아이디어를 축적**하는 로컬 대시보드.

- 최신 앱 흐름
- UX 패턴
- 사용자 반응
- 인기 서비스 구조

---

## 핵심 철학

| | |
|---|---|
| 뉴스 서비스 | ❌ |
| 정보 아카이브 | ❌ |
| 개인 PM 훈련기 | ✅ |

> 대단한 서비스 개발이 목표가 아니다.  
> **매일 꾸준히, 좋은 앱을 많이 보고, 좋은 UX를 저장하는 습관**이 목표다.

---

## 사용 시나리오

### 아침 루틴

```
출근 후 → streamlit run app.py 실행
↓
30분 동안:
  - 뜨는 앱 확인
  - UX 패턴 관찰
  - 저장할 아이디어 북마크
  - 메모 작성
```

---

## 기대 효과

1. **기획 감각 향상** — 어떤 UX가 반복되는지 익힘
2. **사용자 심리 파악** — 사람들이 좋아하는 구조 습득
3. **앱 아이디어 축적** — 기능 조합 아이디어 증가
4. **서비스 패턴 학습** — 성공하는 앱의 공통 구조 분석
5. **트렌드 감각 유지** — AI 앱 흐름, 글로벌 앱 흐름, 커뮤니티 반응
