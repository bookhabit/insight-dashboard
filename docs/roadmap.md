# 개발 로드맵

## 단계 개요

```
1단계 MVP → 2단계 정제 → 3단계 확장 → 4단계 AI (선택)
```

---

## 1단계 — MVP

> 목표: **매일 실제로 보는 수준**

**필수 기능:**
- [ ] Product Hunt RSS 수집
- [ ] Reddit 수집
- [ ] 앱 카드 UI 출력
- [ ] 북마크 저장

**완료 기준:** 매일 아침 실행해서 새로운 앱 5개 이상 확인 가능.

---

## 2단계 — 정제

**추가 기능:**
- [ ] 태그 시스템
- [ ] 키워드 검색
- [ ] 자유 메모 기능
- [ ] 카테고리 필터

---

## 3단계 — 확장

**수집 소스 확대:**
- [ ] App Store 랭킹 (국가별)
- [ ] Google Play 랭킹
- [ ] GitHub Trending

---

## 4단계 — AI 연동 (선택)

> **초기에는 제외 권장.** 습관이 먼저다.

**선택 기능:**
- [ ] 앱 설명 자동 요약
- [ ] UX 패턴 자동 분류
- [ ] 유사 앱 추천
- [ ] 주간 트렌드 리포트 생성

---

## 우선순위 원칙

1. **실제로 쓰는 것** > 완성도
2. **빠른 실행** > 정교한 기능
3. **저장의 마찰 최소화** — 북마크는 클릭 1번
4. AI는 습관이 잡힌 뒤 추가
